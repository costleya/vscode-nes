### Code navigation

Choose navigation tools by the question:

- Serena: symbols, bodies, and references in the selected checkout.
- colgrep: semantic discovery when the concept is known but the symbol or path is not.
- ripgrep (`rg`): literal/regex search and fallback discovery; `rg --files` for file discovery.
- ast-grep: syntax-aware structural search and rewrites.
- jq: parse, filter, and inspect JSON instead of treating structured data as plain text.

If a tool is unavailable, report it once and use an available alternative. Install missing tools only through explicitly requested `$s-obvious-dev-setup`.
